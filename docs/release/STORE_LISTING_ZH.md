## 详细说明

Glintab 是中文优先的网页阅读助手。连接你自己的 AI 模型，在当前网页旁提炼重点、梳理思路，并围绕原文继续提问。

【边读边理解】
点击工具栏图标，在网页右侧打开阅读面板。一键生成摘要，也可以直接输入问题，继续多轮追问。支持停止生成、复制回答，以及编辑最后一个问题重新发送。

【核对模型读到了什么】
查看、复制或下载提取的网页正文，了解内容长度与截断情况。需要更新来源时，可以重新提取，或使用「刷新页面并摘要」。摘要可能出错，请结合原文核对事实和引用。

【连接自己的模型】
支持 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages，以及 Ollama 的 OpenAI 兼容接口。可配置多个供应商，选择模型、流式输出和兼容模型的推理强度；也可导入支持的 Claude Code、Codex、OpenCode 或通用配置。

另提供 ChatGPT 账号的 Codex 兼容授权连接。实际可用性取决于账号权限、地区和平台接口；这不是 OpenAI 官方扩展，也不保证所有账号或模型均可使用。

【按自己的方式总结】
分别设置网页与视频的摘要指令，也可为指定域名设置专属提示词。回答语言可选简体中文、英文或跟随正文。

【视频字幕阅读】
提供 YouTube 与 B 站视频字幕提取入口，可查看带时间戳的字幕、导出 Markdown，并围绕字幕提问。B 站按当前分 P 处理。能否读取取决于视频是否提供可访问字幕、登录状态及平台接口；没有字幕的 YouTube 视频暂不能总结。

可选启用 B 站无字幕音轨转写：需单独配置兼容转写服务并授权，仅用于符合限制的普通投稿视频。有字幕时不下载音轨；不提供麦克风录音、视频画面理解或 YouTube 音轨转写。转写结果可能有误，第三方服务可能收费。

【本地保存，按需发送】
设置、密钥和最近 10 个网址的正文与对话保存在当前浏览器。Glintab 没有自建模型中转服务器、广告、遥测或云同步。当你发起摘要或问题时，必要的标题、网址、正文、问题和历史会直接发送到所选模型服务；启用音轨转写后，相关音频会上传到你指定的转写服务。

API Key 和账号令牌在扩展本地存储中未加密。可在通用设置中清除全部本地数据；已发送到第三方服务的数据由对应服务的政策约束。

【开始使用】

1. 安装后打开扩展设置，添加并保存 AI 供应商，允许访问对应服务域名。
2. 打开普通网页，点击工具栏中的 Glintab 图标。
3. 点击总结，或直接输入问题。需要额外网页权限时，可仅授权当前网站，也可自行选择一次授权所有普通网站。

扩展本身免费，需要自备可用的模型服务或账号权限；相关服务费用由服务商收取。浏览器内置页、扩展商店等受限页面无法提取。平台字幕、ChatGPT 账号连接及第三方转写服务的可用性受外部服务影响。
