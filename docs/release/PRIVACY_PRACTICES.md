# 隐私实践与权限申报

适用于当前 0.1.0 生产 Manifest。上传包后逐项填写商店后台；公开隐私政策使用 [PRIVACY.md](../PRIVACY.md) 或生成的 `privacy-policy.html`。发布者 playwolf719；联系 playwolf719@gmail.com。

## 单一用途（可直接粘贴）

帮助用户理解当前选定的网页或视频文本：按用户操作提取网页正文、视频字幕或可选的 B 站音轨转写文字，交给用户选择的 AI 服务生成摘要并进行后续问答。模型连接、提示词配置和本地阅读历史均服务于这一阅读用途。

## 权限理由（逐项粘贴）

| 权限                                  | 理由                                                                                                                                                                                                                                                                                                                                                                           |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `storage`                             | 在设备本地保存模型服务配置、API Key、账号连接凭证、用户设置、最近 10 个网址的正文与对话，以及抽屉宽度。session 存储仅保存登录和刷新摘要的短期状态；所有持久化写入由后台统一完成，无云同步。                                                                                                                                                                                    |
| `activeTab`                           | 用户点击工具栏图标后临时访问该标签页，按需显示网页抽屉并提取用户指定页面的正文，不常驻读取所有页面。                                                                                                                                                                                                                                                                           |
| `scripting`                           | 在用户指定且已授权的标签页按需注入抽屉和正文提取脚本；视频提取需在页面环境读取播放器字幕或 B 站音轨元数据。不加载远程脚本。                                                                                                                                                                                                                                                    |
| `offscreen`                           | 为不依赖面板存活的专用 Worker 提供宿主，使用户关闭界面后生成仍可完成；可选 B 站音轨转写时在该宿主解码内存中的音频。不录制声音，不使用麦克风。                                                                                                                                                                                                                                  |
| `sidePanel`                           | 在浏览器原生侧栏显示同一阅读与问答界面；与网页抽屉和独立窗口共用界面。                                                                                                                                                                                                                                                                                                         |
| `tabs`                                | 识别来源标签页的标题和网址，将任务绑定到正确的页面，过滤切页后的旧结果，支持面板重连、刷新页面摘要，以及打开设置、授权标签页和独立窗口。不调用浏览历史 API。                                                                                                                                                                                                                   |
| `alarms`                              | 定期检查并关闭空闲的 offscreen 任务宿主、清理过期授权草稿；不会定时抓取网页或发起模型请求。                                                                                                                                                                                                                                                                                    |
| `webNavigation`                       | 在扩展创建的登录标签页捕获固定 ChatGPT 授权回调的主框架导航，包括回调加载失败时的事件。只处理匹配的登录流程，不收集全站导航历史。                                                                                                                                                                                                                                              |
| `declarativeNetRequestWithHostAccess` | 仅在用户启用 B 站音轨转写并授权 CDN 后，为本扩展发往 bilivideo.com / bilivideo.cn 的音轨 XHR 请求设置固定 B 站 Referer。使用 session 规则，不修改普通网页请求；禁用转写或清空数据时删除规则。                                                                                                                                                                                  |
| 可选 `http://*/*`、`https://*/*`      | 用户可配置任意兼容模型/转写端点，也可阅读不同网站，因此在 Manifest 中声明可选 HTTP(S) 范围。安装时不默认授予域名访问权；保存供应商时按域名申请，网页读取可按当前网站申请，或由用户主动选择一次授权全部普通网站。远端模型和转写端点要求 HTTPS，仅回环本机端点允许 HTTP。ChatGPT 连接另申请 auth.openai.com 和 chatgpt.com；B 站转写另申请受限音频 CDN。授权不触发自动全站提取。 |

`web_accessible_resources` 只让网页中的扩展 iframe 能加载包内侧栏和资源，不授予网页读取权限。生产包应无默认 `host_permissions`、无自动 `content_scripts`；runtime 提取脚本的空 `matches` 必须保留。

## 远程代码

选择「不使用远程代码」。说明：

所有可执行 JavaScript、React 界面、正文解析器和任务 Worker 均随扩展打包。网络请求仅获取模型/转写响应、模型目录、授权数据、公钥及视频字幕/音轨数据，不下载或执行远程代码。模型 Markdown 不执行 HTML 或脚本，也不自动加载远程图片。

## 用户数据类型

按扩展处理的数据申报，不能因「没有开发者服务器」或「只存本机」选择全部不处理。当前版本建议勾选下列类型，并与后台实际定义逐项核对：

| 后台数据类型                                       | 当前版本             | 依据                                                                                                   |
| -------------------------------------------------- | -------------------- | ------------------------------------------------------------------------------------------------------ |
| 个人身份信息 / Personally identifiable information | 勾选                 | ChatGPT 连接处理账号邮箱、账号 ID 和身份 token 中的必要账号信息；来源正文也可能包含用户信息。          |
| 身份验证信息 / Authentication information          | 勾选                 | 用户配置的模型与转写 API Key、ChatGPT access/refresh/ID token；本地未加密，鉴权时发送到对应服务。      |
| 个人通信 / Personal communications                 | 勾选                 | 扩展保存并发送用户与助手的问答消息；用户主动选择的网页正文也可能包含通信内容。没有自动读取邮箱的功能。 |
| 网络历史记录 / Web history                         | 勾选                 | 保存并按需发送用户指定来源的网址、标题及最近 10 个网址会话，不收集完整浏览历史。                       |
| 网站内容 / Website content                         | 勾选                 | 提取的正文、字幕、用户问题、必要历史及可选 B 站音轨；音轨只在内存中处理并上传到指定转写服务。          |
| 用户活动 / User activity                           | 不勾选（按当前实现） | 无行为分析、点击流、全局按键/鼠标监控；仅响应扩展内的功能操作和提问。                                  |
| 位置信息 / Location                                | 不勾选（按当前实现） | 不请求地理位置，不通过 IP 推断位置。                                                                   |
| 健康信息 / Health information                      | 无专门采集功能       | 普通正文可能包含此类信息；若发布用途或演示内容涉及健康数据，需相应申报并同步政策。                     |
| 财务和付款信息 / Financial and payment information | 无专门采集功能       | 扩展无付款表单、交易采集或计费系统；若发布用途涉及此类页面，需按实际处理范围申报。                     |

若后台单独提供音频数据类型，也应披露可选音轨转写；不要将「不使用麦克风」解释为不处理音频。用户选择的网页可能包含敏感内容，应在发起请求前检查正文。

数据用途可声明为提供上述阅读功能；不售卖数据、不用于广告、不用于无关目的、不用于信用评估。将必要文本或音频发送至用户选择的服务，是提供相应功能的数据传输，不能笼统申报「完全不向第三方传输」。第三方的保留政策由用户选择的服务决定。
