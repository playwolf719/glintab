# 迭代路线

原始基线：[REBUILD_GUIDE_ZH.md](../REBUILD_GUIDE_ZH.md)。本次交付为 0.1.0 网页与字幕阅读版本，以下是后续候选工作，不代表已实现。

| 版本方向 | 工作                                                  | 验收重点                                     |
| -------- | ----------------------------------------------------- | -------------------------------------------- |
| 网页体验 | 引用片段定位、会话导出、历史管理                      | 引用只定位真实片段；重新提取不误删笔记       |
| 生命周期 | 可选固定抽屉、按标签页恢复开关                        | 全站权限单独申请；拒绝时可手动打开           |
| 长文能力 | 模型能力配置、历史压缩策略、tokenizer                 | 压缩失败可降级；最终请求仍不超预算           |
| 视频适配 | 扩展已有 YouTube / B 站字幕适配，补充真实账号兼容矩阵 | 真实字幕下载、平台风控、分 P、登录与超时恢复 |
| 个性化   | 英文界面、主题（网页/视频独立摘要指令已实现）         | 配置跨窗口同步；无文案超前承诺               |
| 发布准备 | 商店资料、人工权限验收、供应商联调                    | 商店包最小权限；隐私说明与实际网络一致       |
| 可选账号 | 其他平台 OAuth 与授权兼容性验证                       | 单独定义授权、刷新、撤销与过期流程           |

不要在没有完整令牌生命周期时加入“登录即可用”的承诺。新增云服务、遥测或同步前，重新设计数据流并更新隐私说明。
