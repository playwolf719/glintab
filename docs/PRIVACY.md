# Glintab 隐私说明

适用于 0.1.0，更新日期：2026-10-29。

## 本机保存

Glintab 在当前浏览器的扩展本地存储中保存供应商名称、Base URL、API Key、模型和上下文上限、设置，以及最近 10 个网址的正文和对话历史。API Key 未加密，不上传至 Glintab 服务器。导入配置只保存必要字段，不保存粘贴原文。

正文最多缓存 120,000 字符。提取内容可能包含原网页中的个人信息；请在请求前确认当前页面适合发送至你选择的模型。可通过字符数或「查看正文」检查缓存内容。

## ChatGPT 账号接入

选择 ChatGPT 登录时，扩展打开 OpenAI 授权页，使用 PKCE 获取授权。后台仅观察自己创建的登录标签页，捕获固定回调地址的主框架导航并校验 state。不会抓取 ChatGPT Cookie 或网页 session token。此接入使用 Codex 兼容客户端与后端，真实平台可用性仍需联调。

OpenAI access / refresh / ID token 由后台 Repository 保存在浏览器扩展本地存储的独立凭证记录中，**未加密**。存储限制为 TRUSTED_CONTEXTS，不向网站内容脚本开放；供应商配置、界面响应、会话历史和任务广播不携带这些 token。生成 Worker 只通过专用后台通道获取请求所需的 access token 与账号 ID，refresh token 不传给 Worker。短期 PKCE 参数保存在扩展 session 存储，完成或取消后清除敏感参数。

授权、身份签名验证与刷新访问 `auth.openai.com`；模型列表和聊天请求直接访问 `chatgpt.com/backend-api/codex`；模型目录请求附带目录兼容版本 `client_version`，不包含额外用户信息。没有本机代理、常驻服务或 Native Messaging 组件，不读写 Codex 或旧版 `.glintab/auth.json` 文件。已有旧版本文件不会自动迁移或删除，用户可自行清理。

删除 ChatGPT 供应商或清除全部本地数据，会移除此浏览器的凭证，不保证撤销 OpenAI 服务器上的授权。可在 OpenAI 账号设置中管理远程会话和授权。卸载扩展由浏览器处理扩展存储。

## 模型请求

仅在你发起摘要或问题时，插件将网页标题、网址、预算内的正文、问题、必要历史及系统指令发送到你配置的模型服务。获取模型列表会访问该服务的模型列表端点。API Key 与 ChatGPT 模式均直接从插件发往目标服务，受目标服务商的隐私和留存政策约束。

Glintab 没有远程自建服务端、遥测、广告、自有账号体系、付费系统、云同步或数据售卖。扩展本身不加载远程脚本、字体或分析资源；模型返回的 Markdown 图片不发起远程加载。点击回答中的外部链接会按通常浏览行为打开目标网站。

## 权限用途

| 权限              | 用途                                                 |
| ----------------- | ---------------------------------------------------- |
| storage           | 保存配置、密钥、会话和抽屉宽度                       |
| activeTab         | 点击扩展图标后读取当前网页                           |
| scripting         | 按需注入抽屉或正文提取脚本                           |
| webNavigation     | 捕获登录标签页的主框架回调导航，包括加载失败的回调   |
| tabs              | 识别来源标签页与网址，跟踪切页、创建设置页和独立窗口 |
| sidePanel         | 在浏览器原生侧栏中显示阅读界面                       |
| offscreen         | 运行独立于可见界面的 Worker 任务引擎                 |
| alarms            | 定期关闭空闲的任务宿主                               |
| 可选 HTTP(S) 域名 | 按操作申请模型端点或当前网页的访问权限               |

生产包不默认授予全站 host 权限，也不自动提取所有页面。受浏览器限制的页面无法提取正文。

读取权限不足时，可点击「一次授权所有网站」向浏览器申请全部普通 HTTP/HTTPS 网站的访问权限，允许后跨站及新标签页无需逐站授权；也可选择仅授权当前网站。权限由浏览器保存，可在扩展管理页撤回。授予全站权限后仍仅在你发起摘要或提问时提取正文，不自动读取浏览记录或上传页面。

## 删除与保留

删除供应商会移除该供应商的本地密钥。进入「通用设置 → 清除全部本地数据」可删除所有配置、密钥、正文、会话和宽度设置；运行任务需先停止。卸载扩展亦会由浏览器处理扩展存储。

删除数据不会自动撤回已发送到模型服务的内容，也不会自动撤销浏览器已授予的站点权限；可在浏览器扩展管理页修改站点访问权限。
