# Glintab 隐私说明

适用于 0.1.0，更新日期：2026-10-30。

## 本机保存

Glintab 在当前浏览器的扩展本地存储中保存供应商名称、Base URL、API Key、模型和上下文上限、设置，以及最近 10 个网址的正文和对话历史。API Key 未加密，不上传至 Glintab 服务器。导入配置只保存必要字段，不保存粘贴原文。

网页和视频的自定义摘要提示词分别保存在本机设置中，只有执行摘要时才作为该轮问题发往所选模型；旧会话中的摘要指令可能随必要历史发送。恢复默认或编辑提示词后需保存，既有对话不会自动改写。升级会在后台本地迁移配置，保留已有网页指令并补上默认视频指令，不增加网络请求。

域名专属摘要规则的域名和提示词也由后台仓储保存在本机，匹配过程在扩展内执行，不为规则中的网站额外发起请求或申请读取权限。发起摘要时，仅选中的提示词作为该轮问题发送给模型，未匹配规则的列表不会随模型请求上传；先前已用过的指令仍可能随必要历史发送。添加、修改或删除规则需保存，清除全部本地数据会一并删除规则。

正文最多缓存 120,000 字符。提取内容可能包含原网页中的个人信息；请在请求前确认当前页面适合发送至你选择的模型。可通过字符数或「查看正文」检查缓存内容。

视频会话另外保存平台、视频 ID、当前分 P、字幕语言、自动字幕/音轨转写标记和缓存正文对应的时间片段（如有）。不保存字幕或音轨下载 URL、签名参数或完整播放器响应。「查看字幕」或「查看转写」可检查提取内容；复制和下载均为本地操作。

## 视频平台请求

仅在你发起视频总结、首轮提问或重新提取时，Glintab 在当前视频页按需执行字幕读取。YouTube 读取当前播放器的字幕轨道，并访问 YouTube 自身的字幕地址；B 站访问 `api.bilibili.com` 的视频与字幕元数据接口，再访问 `hdslb.com` 字幕 CDN 或 `subtitle.bilibili.com`。字幕响应限制为 4 MB，并设置超时；不发送到第三方字幕代理或转写服务。

视频平台请求可沿用当前网站的登录态，字幕 CDN 下载不携带凭证。扩展不读取、持久化或向模型发送视频站 Cookie，不读取账号凭证，不修改播放器字幕开关，也不安装常驻网络拦截。MAIN world 页面结果仍可能受网站脚本影响，后台会验证来源和数据结构。

字幕、视频标题、网址和所需时间戳链接在你发起总结或问题时按上下文预算发送给所选模型，与网页正文遵循相同的本地历史保留规则。时间戳链接在新标签页打开视频网站；模型没有收到视频画面或音频。

## 可选 B 站音轨转写

默认关闭，需在「语音转写」中配置独立服务并启用。已启用且 B 站明确无字幕时，用户发起总结或问题会触发当前分 P 的音轨下载与转写，可能产生服务商费用；有字幕时不下载音轨。需要登录或字幕接口失败时不自动转写。YouTube 不走此流程，不使用麦克风、不录制标签页声音。

MAIN 中的视频元信息和播放地址请求沿用 B 站登录态，不读取 Cookie 原文；音轨由扩展下载，只访问经过校验的 HTTPS `bilivideo.com / bilivideo.cn` CDN，下载不携带 Cookie。`declarativeNetRequestWithHostAccess` 规则只为本扩展发往这些 CDN 的请求设置固定 Referer，不修改普通网页的网络请求；禁用转写、清空数据或浏览器关闭后清除该 session 规则。

独立的转写 Base URL、API Key、模型 ID 和响应格式由后台 Repository 保存在本机，密钥未加密。音频只在内存中下载、解码和分段，作为 WAV 上传到用户指定的转写服务，不经 Glintab 中间服务器，不发送给文字总结模型。音频接收方遵循其自身隐私和留存政策；即使用户停止或服务请求失败，已上传部分仍可能被计费或留存。转写成功后的文字、视频标题/网址及实际时间片段再按预算发给所选总结模型。

原音频、签名音轨地址及部分转写结果不落盘；完整转写文字作为会话来源保存在本机，后续追问复用它。没有时间戳的服务只保存纯文字。关闭面板后下载和转写继续；停止或切换源视频会中止未完成转写，重新执行可能重复计费。清除全部本地数据也会删除转写服务配置与转写文字，不能撤回已发送给服务商的音频。

## ChatGPT 账号接入

选择 ChatGPT 登录时，扩展打开 OpenAI 授权页，使用 PKCE 获取授权。后台仅观察自己创建的登录标签页，捕获固定回调地址的主框架导航并校验 state。不会抓取 ChatGPT Cookie 或网页 session token。此接入使用 Codex 兼容客户端与后端，真实平台可用性仍需联调。

OpenAI access / refresh / ID token 由后台 Repository 保存在浏览器扩展本地存储的独立凭证记录中，**未加密**。存储限制为 TRUSTED_CONTEXTS，不向网站内容脚本开放；供应商配置、界面响应、会话历史和任务广播不携带这些 token。生成 Worker 只通过专用后台通道获取请求所需的 access token 与账号 ID，refresh token 不传给 Worker。短期 PKCE 参数保存在扩展 session 存储，完成或取消后清除敏感参数。

授权、身份签名验证与刷新访问 `auth.openai.com`；模型列表和聊天请求直接访问 `chatgpt.com/backend-api/codex`；模型目录请求附带目录兼容版本 `client_version`，不包含额外用户信息。没有本机代理、常驻服务或 Native Messaging 组件，不读写 Codex 或旧版 `.glintab/auth.json` 文件。已有旧版本文件不会自动迁移或删除，用户可自行清理。

删除 ChatGPT 供应商或清除全部本地数据，会移除此浏览器的凭证，不保证撤销 OpenAI 服务器上的授权。可在 OpenAI 账号设置中管理远程会话和授权。卸载扩展由浏览器处理扩展存储。

## 模型请求

仅在你发起摘要或问题时，插件将网页标题、网址、预算内的正文、问题、必要历史及系统指令发送到你配置的模型服务。获取模型列表会访问该服务的模型列表端点。API Key 与 ChatGPT 模式均直接从插件发往目标服务，受目标服务商的隐私和留存政策约束。

API Key 供应商可关闭流式输出，等待完整 JSON 回答；这只改变模型响应方式，不增加发送的数据或中间服务。HTTP 400 诊断仅在内存中有限读取错误响应，并显示已知的参数名，不显示、记录或持久化服务端原始错误正文；HTTP 状态与经过筛选的提示可能随失败会话保存在本机。

可选的推理强度随供应商配置保存在本机，仅在发起兼容协议的模型请求时发送给所选服务商；选择「跟随服务端」时不发送该参数。它不增加权限或中间服务，也不请求、显示或保存模型内部思考过程。

Glintab 没有远程自建服务端、遥测、广告、自有账号体系、付费系统、云同步或数据售卖。扩展本身不加载远程脚本、字体或分析资源；模型返回的 Markdown 图片不发起远程加载。点击回答中的外部链接会按通常浏览行为打开目标网站。

## 权限用途

| 权限                                | 用途                                                 |
| ----------------------------------- | ---------------------------------------------------- |
| storage                             | 保存配置、密钥、会话和抽屉宽度                       |
| activeTab                           | 点击扩展图标后读取当前网页                           |
| scripting                           | 按需注入抽屉或正文提取脚本                           |
| webNavigation                       | 捕获登录标签页的主框架回调导航，包括加载失败的回调   |
| tabs                                | 识别来源标签页与网址，跟踪切页、创建设置页和独立窗口 |
| sidePanel                           | 在浏览器原生侧栏中显示阅读界面                       |
| offscreen                           | 运行独立于可见界面的 Worker 任务引擎                 |
| alarms                              | 定期关闭空闲的任务宿主                               |
| declarativeNetRequestWithHostAccess | 仅为本扩展的已授权 B 站音轨 CDN 请求设置 Referer     |
| 可选 HTTP(S) 域名                   | 按操作申请模型端点或当前网页的访问权限               |

生产包不默认授予全站 host 权限，也不自动提取所有页面。受浏览器限制的页面无法提取正文。

读取权限不足时，可点击「一次授权所有网站」向浏览器申请全部普通 HTTP/HTTPS 网站的访问权限，允许后跨站及新标签页无需逐站授权；也可选择仅授权当前网站。权限由浏览器保存，可在扩展管理页撤回。授予全站权限后仍仅在你发起摘要或提问时提取正文，不自动读取浏览记录或上传页面。

## 删除与保留

删除供应商会移除该供应商的本地密钥。进入「通用设置 → 清除全部本地数据」可删除所有配置、密钥、正文、会话和宽度设置；运行任务需先停止。卸载扩展亦会由浏览器处理扩展存储。

删除数据不会自动撤回已发送到模型服务的内容，也不会自动撤销浏览器已授予的站点权限；可在浏览器扩展管理页修改站点访问权限。
